# Images de travail sorties du site publié (3 novembre 2026)

Ces images ne sont plus affichées par le jeu, mais servent de référence ou de matière aux scripts :
- `district/` : les essais de la Cuvette (décors nus, mer peinte, essais de chaque bâtiment, versions v2/v3), lus par
  `scripts/cuvette-detourer-batiments.py` (cuvette2-nue) et cités dans `docs/prompts-cuvette.md`.
- `batiments/<id>-1 à 4` : les anciennes maisonnettes de l'archipel, par palier. La Cuvette n'a pas encore ses paliers peints
  (`PALIERS_PEINTS = false` dans src/ui/art.ts) : les nouveaux paliers prendront ces noms dans public/art/batiments/.

Avant, elles étaient publiées avec le jeu (≈ 11 Mo à télécharger pour rien).
