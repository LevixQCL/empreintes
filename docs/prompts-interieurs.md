# Prompts — intérieurs des bâtiments (12 novembre 2026)

La feuille d'un bâtiment s'ouvre sur une scène peinte de son intérieur (comme la salle d'entraînement de la Tour).
Format paysage 3:2 : l'image est recadrée en bandeau, le centre doit porter l'essentiel, le bas reste calme (le nom s'y pose).
Déposer le fichier dans `public/art/salles/<nom>.webp`, puis l'ajouter à `INTERIEURS` dans `src/ui/art.ts`.
