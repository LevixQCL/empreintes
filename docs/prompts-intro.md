# Prompts Gemini de l'intro

Une seule conversation Gemini pour les 16 plans, format portrait 9:16. Le premier message contient le préfixe de
style complet ; les suivants commencent par « Do not edit the previous image: create a brand-new image from scratch ».
Règle commune ajoutée à chaque prompt : *no text, no letters, no numbers, no signs with writing, no flags, no real
country, no real person, no religious motifs, family-friendly, no blood, no gore. Leave the lower third of the image
calm and simple (it will hold subtitles).*
