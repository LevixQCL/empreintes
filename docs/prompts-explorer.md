# Prompts Midjourney — Explorer ou fouiller (31 octobre 2026)

Six images : les portraits des 4 Rôdeurs, puis 2 icônes (le Vestige, les traces du Rôdeur).
En attendant, le jeu prête aux Rôdeurs le portrait d'un ennemi de leur zone, teinté, et dessine les icônes au trait.

Dépose-les dans ton dossier Téléchargements avec ces noms : je les convertis et je les intègre.
- Portraits : `public/art/ennemis/<id>.webp`, même cadrage que les autres ennemis (vertical, la créature en pied, un peu de décor).
  Le style vient des portraits d'ennemis existants (`--sref`).
- Icônes : `public/art/icones/<nom>.webp`, fond noir pur pour le détourage. Elles s'affichent petites (≈ 20 px sur le plan) :
  une seule forme forte, pas de détail fin.

Rien de gore : les Rôdeurs inquiètent, ils ne font pas peur.
