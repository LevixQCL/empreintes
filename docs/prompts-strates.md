# Prompts Midjourney — le contenu des Strates (31 octobre 2026)

Sept icônes pour les nouveautés des Strates (Haltes, portes à Fréquence, quêtes, passages secrets, murs, fils, bestiaire).
En attendant, le jeu les dessine au trait. Fond noir pur pour le détourage, format carré. À déposer dans
`public/art/icones/<nom>.webp`, puis ajouter le nom dans `PEINTES` (src/ui/icones.ts) : le jeu prend l'image peinte d'office.
Elles s'affichent petites (≈ 20 à 50 px) : une seule forme forte, pas de détail fin.
Les Haltes utilisent le décor de leur Strate (déjà peint) : aucune nouvelle illustration n'est nécessaire pour la première version.
