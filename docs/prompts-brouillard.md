# Prompts Midjourney — les indices du brouillard (30 octobre 2026)

Six icônes pour les salles voilées du plan des Strates : elles remplacent les tracés au trait dans le médaillon de verre fumé.
Fond noir pur pour le détourage, format carré. À déposer dans `public/art/icones/<nom>.webp` (bruits, lueur, silence, traces,
chaleur, brume), puis ajouter le nom dans `PEINTES` (src/ui/icones.ts) : le jeu prend l'image peinte d'office.
Elles s'affichent petites (≈ 25 px sur la carte, ≈ 35 px dans la fiche) : une seule forme forte, pas de détail fin.
